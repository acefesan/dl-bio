The paper's practical advice

  • Every method except ssGSEA does well once the gene set has more than 100 genes.
  • For sparse gene sets of 10–50 genes, use AUCell or JASMINE.
  • Below 50 cells, don't use scPS.
  • If the groups you compare differ in how many genes they detect, every method except scPS will report differences that aren't there.
  • Rank-based methods are more prone to false positives, because they react to rank changes rather than to the size of the change.
  • Zero imputation improved every method, but it also changes the data's distribution, and it hurt SCSE at high noise.
