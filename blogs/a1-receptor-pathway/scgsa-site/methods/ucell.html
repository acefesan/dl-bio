Rank · Mann–Whitney

UCell

Treat the question as a two-sample test inside one cell: do the set's genes rank higher than the cell's other genes? Answer with a normalised Mann–Whitney U statistic, counting only the top 1,500 ranks.

The question it asks

A Mann–Whitney U test compares two samples by counting, across all pairs, how often an item from one sample outranks an item from the other. UCell (Andreatta & Carmona 2021) runs this within a single cell: sample one is the set's genes, sample two is every other gene. If the set's genes consistently outrank the rest, the set is active.

Unlike AUCell, UCell uses every set gene's rank, not just whether it crossed a line — until the cap. Genes below rank 1,500 are all treated as rank 1,500.

The computation

Rank the cell's genes highest-first, averaging ties. Cap each set gene's rank at \(R_{\max}\) (any rank beyond it counts as \(R_{\max}\); the paper's pipeline uses 1,500). For a set \(S\) of \(k\) genes, let \(r_1, \dots, r_k\) be the capped ranks of its genes, where rank 1 is the most highly expressed gene, and \(i\) indexes the set's genes:

$$\text{UCell} = 1 - \frac{\sum_i r_i - \frac{k(k+1)}{2}}{k \cdot R_{\max} - \frac{k(k+1)}{2}}$$

Where each piece comes from:

  • \(\sum_i r_i - k(k+1)/2\) is the Mann–Whitney \(U\): the number of (set gene, other gene) pairs in which the other gene ranks higher. If the set occupies ranks \(1, \dots, k\), the sum of ranks is exactly \(k(k+1)/2\) and \(U = 0\).
  • \(k \cdot R_{\max} - k(k+1)/2\) is the largest \(U\) can be once ranks are capped: every set gene at the cap.
  • So the score is 1 when the set sits at the very top, and 0 when every set gene is at or beyond the cap.

On our toy cell

Use \(R_{\max} = 5\) for illustration. B = 3, D = 4. G is one of four tied zeros at ranks 7–10, so it gets their average, 8.5, then the cap, 5.

$$\text{UCell} = 1 - \frac{(3 + 4 + 5) - 6}{3 \cdot 5 - 6} = 1 - \frac{6}{9} = 0.33$$

The same number as AUCell on this cell, by coincidence. Move B from rank 3 to rank 2 and UCell rises to 0.44 — it responds to every rank inside the window, where AUCell responds to crossings.

What the benchmarked code does

The paper passes ucell.MaxRank = NULL; irGSEA replaces it with 1500. Ranking uses frankv(..., ties.method = "average", order = -1). UCell's scoring function, verbatim:

insig <- rank_value >= maxRank
if (all(insig)) return(0L)
rank_value[insig] <- maxRank
rank_sum     <- sum(rank_value)
rank_sum_min <- len_sig * (len_sig + 1) / 2
1 - (rank_sum - rank_sum_min) / (len_sig * maxRank - rank_sum_min)

Note that 1,500 is a number of genes, not a fraction. With ~20,000 genes it is the top 7.5%; on HBCA's 58,232 genes it is the top 2.6%. The method becomes stricter as the gene list grows.

Zero policy, and what leaks in

Zeros: all tied at the bottom, averaged, then capped. In practice a zero is always "at the cap" — worth the minimum.

From outside the set: every other gene's rank, inside the top 1,500. Any gene rising into that window pushes set genes down by one rank each.

Where the toy disagrees

In the dense toy of the playground, UCell falsely flags nearly all scenario-1 null gene sets, against the paper's 1–12%. The window size relative to the number of dense signal genes differs between the toy and the paper's data, and UCell's behaviour depends heavily on it. Treat the toy's UCell numbers as illustrating the mechanism, not the magnitude.

On our A1 data

UCell ranked Hippocampal CA4 1st on the 8-gene panel and 5th on the 61-gene panel, and gave CA4 its strongest separation from all other cells (a random CA4 cell outscores a random other cell 79% of the time; Mann–Whitney p = 4.6 × 10⁻⁴³). On 58,232 genes its window is only the top 2.6%, so it is scoring whether the A1 genes are among a neuron's roughly 1,500 most expressed genes.
