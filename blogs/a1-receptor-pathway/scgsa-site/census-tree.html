A tree of every cell type in the Census

Yes, you can build one. The Census labels each cell with a term from the Cell Ontology (CL), and CL already says which types are kinds of which. This page draws that hierarchy for the 10x primary cells, sizes each branch by how many cells it holds, and can colour every branch by how much of an adenosine receptor its cells express.

How to read it

Each row is a cell type. Click the arrow to open its sub-types. The blue bar is the number of 10x primary cells in that type including all its sub-types (log scale). The coloured chip is the percentage of those cells that express the gene you pick, counting only cells from datasets that listed the gene (see the zero page). Hover a row for the exact numbers.

How this tree was made

1. Cell types. From the 10x primary cells, take the Census field cell_type_ontology_term_id (e.g. CL:0000540, "neuron"). Human has 835 distinct terms among these cells; mouse has 387. Cells with no CL term (the value "unknown") are left out of the tree.

2. Ancestors. For each term, the cellxgene-ontology-guide package (the same CL release the Census is curated against) lists every ancestor, i.e. every broader type it is a kind of. Adding all ancestors gives the full set of branches, including intermediate ones no cell is labelled with directly ("neural cell", "native cell", …).

3. Counts. The counts follow the "Cells" and "Sample" buttons. A branch's count is the number of cells whose label is that branch or any descendant of it, so counts are exact and always shrink going down. The group tables behind this come from census_gene_groups.py.

4. The one approximation. CL is not strictly a tree: a type can have two parents (a "cardiac muscle cell" is both a muscle cell and a heart cell, say). To draw a tree, each branch is placed under the parent that holds the most cells, and its other parents are listed in the hover text as "also under". So a branch's counts are exact, but its drawn children do not always add up to it, because a child may be drawn under its other parent.

5. The chip. For the chosen gene: cells in this branch whose count is above zero, divided by cells in this branch that come from datasets which listed the gene at all. The colour scale runs from 0 to the 98th percentile of that value among branches with at least 1,000 such cells, so each gene uses its own range. Branches with fewer than 100 measurable cells show no chip because the percentage is too noisy to mean anything.

6. What this tree is not. These are the Census's cell types: the nearest CL term the curators assigned to each dataset's own labels. They are coarser than a dataset's native clusters (for example the 21 HBCA superclusters we scored earlier map onto a smaller set of CL neuron terms), and the authors' original labels live in the dataset files, not in the Census table.
