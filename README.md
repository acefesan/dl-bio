## Chapter 2: Protein Embeddings & Clustering

Pipeline that generates ESM2 embeddings for ~141k protein sequences, joins them with functional and evolutionary annotations, and analyzes how well the embedding space captures biological structure.

### Pipeline

Run from the project root with the venv activated (`source .venv/bin/activate`).

**Step 1 — Compute ESM2 embeddings**

```bash
python chapters/chapter2/01_compute_embeddings.py              # full run
python chapters/chapter2/01_compute_embeddings.py --limit 100  # test run
```

Reads `assets/proteins/datasets/train_sequences.fasta`, runs each sequence through `facebook/esm2_t33_650M_UR50D`, and saves mean-pooled 1280-dimensional embeddings to `assets/proteins/datasets/all_species_embeddings.feather`. Supports checkpointing and `--resume`.

**Step 2 — Build merged dataset**

```bash
python chapters/chapter2/02_build_dataset.py --hog-cache assets/proteins/datasets/cafa3_merged/hog_cache.csv
```

Merges sequences, taxonomy, GO term annotations, pre-computed embeddings, and HOG assignments (from OMA) into a single `cafa3_with_embeddings.feather` file (~1.8 GB). Use `--skip-taxonomy` to skip UniProt API calls, `--fetch-hogs` to re-fetch HOGs from scratch.

**Step 3 — Clustering analysis**

```bash
python chapters/chapter2/03_clustering_analysis.py
```

Loads the merged dataset, runs KMeans clustering in the original 1280D embedding space, computes silhouette scores (cosine metric), and generates UMAP visualizations colored by taxa and HOGs. Outputs go to `chapters/chapter2/results/`.

### Pipeline runner

A config-driven runner executes any combination of the 3 steps above. Parameters are stored in a JSON config for reproducibility.

```bash
python chapters/chapter2/run.py                           # run all steps from config.json
python chapters/chapter2/run.py --config my_run.json      # custom config
python chapters/chapter2/run.py --steps 3                 # only clustering
python chapters/chapter2/run.py --steps 2,3               # dataset + clustering
```

Each run creates a timestamped directory under `chapters/chapter2/runs/` containing the config used and step outputs (dataset, clustering). See `chapters/chapter2/config.json` for the default parameters.

### Data

All raw and derived datasets live under `assets/proteins/datasets/` (git-ignored, regenerated by the pipeline):

| File | Description |
|------|-------------|
| `train_sequences.fasta` | CAFA3 training protein sequences (~141k) |
| `train_taxonomy.tsv.zip` | Protein to taxonomy ID mapping |
| `train_terms.tsv.zip` | Protein to GO term annotations |
| `go_term_descriptions.csv` | GO ID to description mapping |
| `all_species_embeddings.feather` | Pre-computed ESM2 embeddings (1280 dims) |
| `cafa3_merged/` | Merged dataset + HOG cache + metadata |
