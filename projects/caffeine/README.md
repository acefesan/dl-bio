# Caffeine epigenome project

Standalone project (not part of the book chapters). Goal: computationally predict caffeine's epigenomic effects across every human cell type by integrating public atlases with the sparse direct-caffeine data that exists.

**Status:** proposal + first lab + concept wiki.
