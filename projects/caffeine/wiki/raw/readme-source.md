## Summary

The project is a standalone caffeine epigenome project outside the book chapters. Its goal is to computationally predict caffeine's epigenomic effects across every human cell type by integrating public atlases with sparse direct-caffeine data.

The README describes the project as proposal-only, but the repository now also contains one active lab under `lab/001_adora_expression/`.
