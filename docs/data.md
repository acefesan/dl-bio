# Data

All raw and derived datasets live under `assets/` (git-ignored — regenerated by the pipelines).

## CAFA3 (broad analysis)

| File | Description |
|---|---|
| `assets/proteins/datasets/train_sequences.fasta` | CAFA3 training protein sequences (~141k) |
| `assets/proteins/datasets/train_taxonomy.tsv.zip` | Protein → taxonomy ID |
| `assets/proteins/datasets/train_terms.tsv.zip` | Protein → GO term annotations |
| `assets/proteins/datasets/go_term_descriptions.csv` | GO ID → description |
| `assets/proteins/datasets/all_species_embeddings.feather` | Pre-computed ESM2 650M embeddings (1280D) |
| `assets/proteins/datasets/cafa3_merged/` | Merged dataset + HOG cache + metadata |

## OMA (mammalian focused)

| File | Description |
|---|---|
| `assets/oma/oma-seqs.fa.gz` | OMA bulk FASTA (5.0 GB, stream-scanned) |
| `assets/oma/protein_lists/*.feather` | Per-species protein lists (fetched from OMA API) |
| `assets/oma/sampled_proteins.feather` | HOG-balanced sample across 30 species |
| `assets/oma/mammalia_dataset.feather` | Final merged dataset (used by `hog_umap.py`) |

## Pretraining (from scratch)

UniRef sequences — tracked by the pretraining scripts; paths in the shell drivers under `chapters/chapter2/run_*.sh`.

## Checkpoints

ESM2 pretraining checkpoints under `checkpoints/` (git-ignored). Inference uses HuggingFace cached models.
